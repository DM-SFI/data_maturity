# כלי אבחון בשלות דאטה ארגונית

> פותח על-ידי [Social Finance Israel (SFI)](https://sfi.org.il/) — יחידת הדאטה והמדידה

---

## מה זה?

כלי דיגיטלי לאבחון עצמי של רמת בשלות הנתונים בארגון. הכלי מאפשר לארגונים חברתיים ורשויות מקומיות לקבל תמונת מצב מהירה ומדויקת על מצב העבודה מבוססת הנתונים שלהם — כנקודת מוצא לחשיבה, לתכנון ולשיפור.

הכלי מבוסס על מסגרת אסטרטגיית הנתונים של SFI, ומודד **בשלות נתונים** — המידה שבה ארגון מיישם אסטרטגיית נתונים ומייצר מתוכה ערך ממשי.

---

## מצב נוכחי

הגרסה הנוכחית היא **פרוטוטיפ פרונט-אנד** — קובץ HTML יחיד, פועל לחלוטין בדפדפן, ללא שרת או בסיס נתונים. הוא מאפשר מילוי שאלון, חישוב ציונים, והצגת דוח מיידי.

---

## מבנה השאלון

השאלון כולל **6 ממדים** (פרקים), כל אחד מודד היבט אחר של בשלות הנתונים:

| # | ממד | תיאור |
|---|-----|--------|
| 1 | מטרות, יעדים ושאלות | האם יש תיאוריית שינוי סדורה? האם נתונים משמשים לתכנון, למידה ומדידה? |
| 2 | כלים ותשתיות | איסוף, שמירה, ניהול ודיווח נתונים — כלים ומערכות |
| 3 | איכות הנתונים | דיוק, עדכניות, שלמות ונגישות הנתונים |
| 4 | תרבות ארגונית | קבלת החלטות מבוססת נתונים, מיומנויות, מנהיגות |
| 5 | פרטיות ואבטחה | מדיניות, נהלים וביקורות אבטחת מידע |
| 6 | שיתופי פעולה | שיתוף בין-מחלקתי, גורמים חיצוניים ושקיפות לתושבים |

> **הערה:** האפיון המלא (ראו `אפיון שאלון אבחון.docx`) מגדיר גם ממדים של שגרות, מיומנויות ואתיקה/משילות — חלקם שולבו בגרסה הנוכחית תחת ממדים אחרים, וחלקם מיועדים לפיתוח עתידי.

## סוגי שאלות

| סוג | תיאור | ניקוד |
|-----|--------|--------|
| `checkbox` | כן/לא ("קיים" / "לא קיים") | 0 או 1 |
| `scale` | סקאלה 1–5 | 1–5 (אפשר להפוך עם `reverse: true`) |
| `radio` | בחירה מרשימה | 1 עד מספר האפשרויות |
| `section` | כותרת עם תת-שאלות | מסכם את תת-השאלות |

### היפוך ניקוד (`reverse`)
שאלות שבהן ציון **גבוה** מבטא **מצב גרוע** מסומנות עם `reverse: true`. הניקוד מחושב `6 - דירוג`, כך שדירוג 1 = 5 נקודות, ו-5 = 1 נקודה.

## מערכת המשוב

כל שאלה יכולה להפיק **תובנה ממוקדת** שמוצגת בדוח הסופי רק כשיש פער משמעותי. שלושה מנגנוני משוב:

- **`trigger`** — פונקציה מותאמת שמחזירה משוב בתנאים מורכבים
- **`feedbackByAnswer`** — מילון משוב לפי ערך (לשאלות רדיו)
- **`lowThreshold` + `lowFeedback`** — משוב אוטומטי אם הניקוד מתחת לסף (לסקאלה)
- **`groupTrigger`** — משוב שמתייחס לקבוצת תת-שאלות כיחידה אחת

## ארכיטקטורה טכנית

```
index.html
├── <style>          עיצוב — CSS variables, RTL, Heebo font
├── <body>           ממשק המשתמש — מסך פתיחה, שאלון, ניווט, דוח
└── <script>
    ├── assessmentData[]   הגדרת כל השאלון (נתונים, טיפוסים, משוב)
    ├── answers{}          מצב התשובות הנוכחי
    ├── renderQuestions()  בניית ה-DOM מ-assessmentData
    ├── setBinary / selectScale / selectRadio   טיפול בתשובות
    ├── calculateScores()  חישוב ניקוד לפי ממד וסה"כ
    ├── showResults()      הרכבת דוח + גרף רדאר
    ├── renderRadarChart() SVG רדאר ידני (ללא ספריות חיצוניות)
    └── exportResults()    ייצוא CSV
```

הכלי כולל:
- **גרף רדאר** — SVG מקורי, ללא תלות בספריות חיצוניות
- **ייצוא CSV** — כולל ממדים, ציונים, תובנות וממצאים
- **הדפסה** — עיצוב print מובנה
- **Responsive** — מותאם למובייל ומחשב

## איך להריץ

```bash
# פשוט פתח בדפדפן:
open index.html

# או הגש עם שרת מקומי:
npx serve .
```

לא נדרש התקנה, בנייה, או חיבור לשרת.
